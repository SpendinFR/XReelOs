# XReel OS Unity project

Open this directory with Unity `6000.0.23f1`. The proprietary XREAL SDK is not
stored in Git; follow the root [README](../README.md) and
[build guide](../docs/BUILD_GUIDE.md) before opening the project.

The community player is generated by:

- scene builder: `WorldCreatorSceneBuilder.BuildCommunityOsScene`;
- Android builder: `AndroidBuildXreal.BuildXReelOsApk`;
- package: `com.spendinfr.xreelos`;
- output: `build/android/XReelOs.apk`.

The scene starts in OS-only mode: the spatial dock, settings, hand/gaze
interaction and app surfaces are enabled; the original creator workspace and
Memory transport are not instantiated.
